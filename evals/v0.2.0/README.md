# Evals v0.2.0 - incuway behavior suite

This directory holds the reusable eval inputs and benchmark summaries used to validate the `v0.2.0` skill changes, plus a runner-agnostic behavior suite for the incuway skills.

What is intentionally committed here:
- eval definitions
- per-iteration benchmark summaries
- analyzer notes
- small iteration READMEs

What is intentionally not committed here:
- raw generated transcripts
- review HTML files
- generated output artifacts from each run
- temporary benchmark workspaces

The full generated workspaces remain local under `skill-evals-workspace/` and are ignored by git.

## Behavior suite

This suite evaluates agent behavior for the incuway skills. It is intentionally runner-agnostic: a subagent or external harness consumes each task, runs the evaluated agent in the fixture workspace, captures evidence, and scores against `verification.md` plus the shared rubric.

The shell evals at `evals/isolation-choice.sh` and `evals/no-auto-commit.sh` remain cheap static smoke checks. The v0.2.0 tasks test behavior.

### How To Consume A Task

1. Choose a task in `tasks/<task-id>/`.
2. Prepare a clean workspace from `fixture/`.
3. Run the evaluated agent with the contents of `instruction.md`.
4. Capture available evidence.
5. Evaluate `verification.md` with `rubric.md`.
6. Emit a report compatible with `schema.md`.

### Evidence Types

- `filesystem`: final file listing.
- `git_diff`: diff against the initial fixture.
- `artifacts`: files generated by the agent.
- `final_message`: last visible agent message.
- `transcript`: full trajectory when available.
- `command_log`: commands executed when available.
- `stdout_stderr`: command output when available.

If optional evidence is unavailable, checks that depend only on it should be marked not evaluable and complemented with manual rubric review.

### Tasks

| Task | Focus |
|------|-------|
| `dev-isolation-choice-before-files` | Development skill must ask branch vs worktree before creating PRD, plan, code, or docs. |
| `dev-no-auto-commit-suggest-prepare-pr` | Development skill must never commit/push/open a PR itself — it only suggests invoking `incu-way-prepare-pr`. |
| `po-gate1-split-before-tickets` | PO skill must stop at Gate 1 (scope and ticket split) before drafting any ticket, surfacing ambiguities as open questions. |

### Delegation Prompt

```text
Run evals/v0.2.0/tasks/<task-id>. Use instruction.md as the prompt for the evaluated agent, prepare the fixture workspace, capture all available evidence, and report against verification.md and evals/v0.2.0/rubric.md. There is no repo runner for this suite by design.
```
